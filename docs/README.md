# Documentación

Esta carpeta reúne la documentación mantenida del repositorio. La integración
Livoltek se instala con HACS. `addons/` queda reservado para posibles proyectos
futuros, pero actualmente no se publica como repositorio de la tienda de
complementos.

## Guías

- [Instalación](installation.md): HACS, actualización y repositorio de add-ons.
- [Configuración](configuration.md): credenciales, dispositivos y opciones.
- [Entidades y sensores](sensors.md): entidades creadas y unidades.
- [Diagnóstico](troubleshooting.md): errores frecuentes y recopilación segura.
- [Mantenimiento](maintenance.md): actualizaciones, copias y rollback.
- [Desarrollo](development.md): estructura, validaciones y pull requests.
